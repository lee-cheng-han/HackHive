# Course Images

## How to add course images:

1. **For the Advanced AI Sentence Practice course:**
   - Place your course image as: `/public/images/advanced-ai-course.jpg`
   - Recommended size: 400x180 pixels (or 2:1 aspect ratio)
   - Supported formats: JPG, PNG, WebP

2. **Image guidelines:**
   - Should represent Indigenous language learning
   - Could show: traditional symbols, learning elements, AI/tech themes
   - Keep cultural sensitivity in mind
   - Bright, engaging visuals work well with the earth-tone theme

3. **Current setup:**
   - The course thumbnail is set to `/images/advanced-ai-course.jpg`
   - Place your image file in this directory with that exact name
   - If no image is found, it will show a default school icon

## Alternative options:

If you don't have an image ready, you can temporarily use:
- An emoji (change `thumbnail: '/images/advanced-ai-course.jpg'` to `thumbnail: '🎯'`)
- A URL to an online image
- Leave it undefined for the default school icon
